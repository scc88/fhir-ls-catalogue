# Source data issues and modelling assumptions

Generated by the build; each item is an inconsistency in the SakuraBloom R2 mock-up or an assumption made while structuring it.

- CP-8 is named '3,5-bis(trifluoromethyl)benzyl bromide' (C9H3BrF6, 307.03, CAS 32247-96-4) in 2.3.3.SM.D but '1-bromo-3,5-bis(trifluoromethyl)benzene' (C8H3BrF6, 293.01) in the impurity tables of 2.3.4.DS.C / 3.2.RS; the starting-material identity was used and the alternative recorded as a synonym.
- Ethanol is used in Steps 2-4 of the drug-substance process and controlled by IPC#1, but no 2.3.3.RM specification page exists for it; a SubstanceDefinition without specification was created.
- Pack sizes (number of tablets per bottle / blister) are not stated in the mock-up; containedItem.amount was omitted.
- DS specification 'Particle size distribution d(0.1)' gives a nominal value ('d(0.1) - 26 nm') without tolerance; stored as text criterion only (no Range).
- DS specification 'Particle size distribution d(0.5)' gives a nominal value ('d(0.5) - 40 nm') without tolerance; stored as text criterion only (no Range).
- DS specification 'Particle size distribution d(0.9)' gives a nominal value ('d(0.9) - 66 nm') without tolerance; stored as text criterion only (no Range).
- Drug substance Step 4: the raw-material column lists water as '20 to 35% w/w of ethanol' whereas CPP #4.1 states 25-35 %; the CPP range was used for the control and the raw-material text kept verbatim.
- Clinical drug-product batches xyz123/456/789 list a batch size of '2,600,00 tablets' (typo); 2,600,000 tablets was assumed. They all list the same drug-substance batches A221221-A221223 and no DS source.
- DP batch analysis Table 2-1 quotes the shelf-life limit for CP-9-1 (NMT 0.5 %) rather than the release limit (NMT 0.3 %); results are linked to the specification test definition, which carries both contexts.
- Testing site for DP batch-analysis results is not stated per test; chemical tests were attributed to Dakina Analytica SA and microbiology to Kunchen SA per the facilities table (assumption).
- DP stability (bottle, Table 2-1   ): row '6 months' for ABC789 appears before any storage-condition heading; skipped.
- DP stability (bottle): duplicate row for ABC123 40c75 6 months in 'Table 2-2 Physical data, Sakura Bloom 20'; first occurrence kept.
- DP stability (blister, Table 2-2 Ph): storage-condition heading missing for ABC123 after the initial result (blank row); assumed 25 °C/60 % RH by analogy with the other tables.
- DP stability (blister): duplicate row for ABC123 40c75 6 months in 'Table 2-2 Physical data, Sakura Bloom 20'; first occurrence kept.
- DP photostability tables for ABC456 / ABC789 label the batches 'AB4563' / 'AB7893'; mapped to ABC456 / ABC789 based on table captions.
- DP microbial enumeration stability tables (3-7) do not state the long-term storage condition; specimens were created with condition 'long-term (not specified)'.
- Elemental impurities: unit for Mg given as 'g/g' (likely a typo for µg/g); value copied as stated.
- Elemental impurities: unit for B given as 'mg/g' (likely a typo for µg/g); value copied as stated.
