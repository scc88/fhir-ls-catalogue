Showcases · CMC · PQI maturity types

FHIR PQI Types 1–4, shown on one example dossier

The HL7 PQI implementation guide now defines four maturity types for CTD quality documents. Each type is a FHIR document that adds one layer to the type before it. These showcases put the same synthetic CTD quality dossier (Module 2.3 plus the 19 Module 3.2 documents) at each type, so you can see what each step adds and who benefits from it.

Type 2 adds the Product data section, whose narrative is generated. Type 4 links fewer passages than Type 3 because the replaced sections no longer have authored text to link. The resource count of Type 4 is that of Type 3: the same resources, used as the record.

About the data

Synthetic example data. The documents are fictitious. Their content comes from the ICH M4Q(R2) Sakura Bloom mock-up, the FDA example Quality Overall Summaries and the synthetic example data of the HL7 FHIR PQI team. They do not describe a real product, company or authorization; every resource is labelled as test data (HTEST). The examples are in sakura-bloom-r2/fhir/pqi-types of this site's repository, and the type definitions are in the PQI implementation guide (continuous build).

Every reference in the Type 3 and 4 documents resolves inside the document itself, including the ObservationDefinitions behind each specification test. Figures the mock-up extract did not include were rebuilt from the mock-up's own data, the HL7 PQI example data or ICH M7; each figure's DocumentReference says how it was made, and where a value had to be made up.
